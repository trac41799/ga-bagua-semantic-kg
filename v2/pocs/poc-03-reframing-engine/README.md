## The 8 moves are EXACT operators (never free-form)
State = (blade_index, sign), blade = 3-bit line mask (bit0 = bottom line),
matching the repo convention (`v2/probes/path-c`): Kun=0, Zhen=1(e1), Kan=2(e2),
Gen=4(e3), Dui=3(e12), Xun=6(e23), Li=5(-e31=e13), Qian=7(e123).

| # | move | effect |
|---|------|--------|
| 1 | `origin` | the original position (8th cube vertex) |
| 2–4 | `flip0`, `flip1`, `flip2` | single-line flips: `blade ^ (1<<line)` |
| 5–7 | `double_flip01`, `double_flip02`, `double_flip12` | two-line flips (compose) |
| 8 | `complement` | antipode: Hodge dual ·e123 → `blade ^ 0b111`, sign × dual_sign |

The 8 positions are the 8 vertices of the 3-bit cube Q3 from the start vertex:
origin + 3 face-neighbors + 3 distance-2 vertices + the antipode.
`all_positions` raises on degenerate (non-distinct) output.

### Complement identity check (natural convention)
| trigram | dual | exact state |
|---------|------|-------------|
| Kan  | Li   | (2,+1) → (5,−1) |
| Gen  | Dui  | (4,+1) → (3,+1) |
| Zhen | Xun  | (1,+1) → (6,+1) |
| Kun  | Qian | (0,+1) → (7,+1) |

Blade-wise all four identities hold exactly. Sign note: under the `·e123`
convention `dual(e2) = −e13`, so Kan→Li carries sign −1; the state's sign
component absorbs the orientation (no convention yields +1 for all eight
trigrams; complement is a sign-reversing involution, complement⁴ = identity).
This is why states are (blade, sign) pairs.

### Start state (protocol detail the pre-registration left open)
`START_STATE = KUN (0, +1)` — the neutral/empty trigram; the 8 positions are
the cube's full orbit from the neutral vertex. Documented here so the real run
is reproducible.
