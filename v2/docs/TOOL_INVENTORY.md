# Tool Inventory

Portfolio snapshot (2026-08). Evidence policy: every tool below is honest about what it is — deterministic math tools are verified to machine precision; LLM-backed tools only pass when their preregistered bars are met; nothing here is claimed as a market-validated product (portfolio recommendation: `TECHNICAL_BETA`).

## Notes

- **Models tested so far:** deepseek-chat (original B1–B4 baseline), `deepseek-v4-flash` (G16 re-run 2026-08; B1/B2/B3 PASS, B4 smoke FAIL on state_diff), `openai/gpt-4o-mini` (POC-15 replication: coverage PASS, reframe FAIL — model-dependent).
- **Offline vs online:** every tool has a `--sim`/offline mode (deterministic SimulatedLLM). Real mode always needs an explicit API key; keys are read from `DEEPSEEK_API_KEY`/`OPENROUTER_API_KEY` env vars or the repo-root `.env.local`.
- **Promotion status:** technical beta only. External-user/task-time/adoption/competitor evidence does not exist yet, so Yarrow (`PENDING`) and all product rows stay un-promoted. Claims that are FAIL or INCONCLUSIVE remain blocked on the matrix (A, B, D, POC-01/03/04/07/09, POC-15-R08, POC-06/10).
- **Where each tool fits** the conversation about "net value": the three deterministic math tools carry the mechanical proof; the LLM-backed tools carry the validated protocol; the QA/provenance tooling keeps the honesty guarantee.
