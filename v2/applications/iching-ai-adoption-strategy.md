# I-Ching × AI Adoption Strategy — With and Without Geometric Algebra

**Date:** 2026-08-08 | **Status:** Evidence-graded strategy, from 8 pre-registered experiments
**Governing verdict (banked):** *I-Ching is an interpretation/naming system, not a computation system. GA computes — perfectly. Bagua names — inconsistently under forced classification; coherent as structure and as generated interpretation.*

**Adoption rule derived from the evidence:** use I-Ching in AI where *structuring, naming, or framing* adds value; never where *discrimination, prediction, or computation* is required. Every unproven application below requires pre-registration before build (house rule).

## 2. Applications WITHOUT GA (LLM-native) — evidence-graded

### 2.1 Decision-framework as a coverage rubric ⭐ highest promise (unproven, pre-register)
**Idea:** use the 8 roles as a *generative completeness checklist*, not a classifier. When an LLM drafts a plan/argument/design, prompt it to check coverage across the 8 aspects ("does this plan address constraint, transmission, balance, influence, clarity, initiation, reception, generation?") — the roles become an audit *prompt*, producing more complete outputs.
**Why this is honest:** POC-04 failed at *discriminative* tagging (66.7% agreement) — but that failure says nothing about *generative* checklist use, which never requires discrimination. The roles are being used as a thinking scaffold, which is exactly what a naming system is for.
**Pre-registration needed:** "LLM plan completeness with vs without 8-role coverage checklist" — human-rated coverage of a fixed aspect list (e.g., missing-aspect count) on 20 planning tasks; delta ≥ 1.0 missing-aspect reduction, n≥5 raters.

### 2.2 State-diff vocabulary for agent introspection (unproven, pre-register)
**Idea:** the 3-line structure is a genuine 3-bit state; "which line changed" is a real, explainable aspect-partition. Use it as a *structured event-summarization template* in agent memory: when an agent's state changes, summarize the change as {aspect1, aspect2, aspect3} deltas with human-readable aspect labels. The bit structure is exact (V3); the labels are generated by the LLM per context.
**Why honest:** uses the framework's only mathematically real structure (3 independent aspects + change = bit flips), never its semantics.
**Pre-registration needed:** "do structured 3-aspect change summaries improve human comprehension of agent state transitions vs free-form summaries?" (human eval, comprehension quiz).

### 2.3 Closed reframing grammar for ideation (directionally supported, re-pre-register)
**Idea:** POC-03's 8 cube positions (3 flips, 3 double-flips, complement) generated *more diverse* reframes than free-form (+0.082) but missed the bar; the weak link was per-position naming (coherence 2.8). As an LLM *prompt grammar* (not a claim engine): "generate the 8 structurally distinct views of this idea: [explicit moves]" — with few-shot naming.
**Why honest:** the moves are exact operators (V3); naming quality is an LLM-protocol variable, fixable and testable.
**Pre-registration needed (v2):** few-shot naming protocol; re-derived margin; same 20 statements frozen + new keys.

### 2.4 Situation-labeling as generated interpretation (unproven, pre-register; scope-limited)
**Idea:** LLM maps a situation to a hexagram + line-dynamics *interpretation written by the LLM* — as a human-facing interpretive lens (agent self-reports, decision reviews), explicitly NOT a forced tag. POC-04's 66.7% tag quality forbids discriminative use; generative interpretation is a different mechanism.
**Why honest:** the output is prose the LLM composes *around* the structure; the structure only frames the writing.
**Pre-registration needed:** "do hexagram-framed agent explanations improve user comprehension/trust vs plain explanations?" (human eval; no accuracy claims).

### 2.5 Teaching & interpretability bridge (validated build, human gate open)
Path C (single-file teaching tool) — the human-facing bridge for both engineers and cultural learners. Human gate pre-registered (≥60% quiz improvement, ≥70% Likert ≥4).

## 3. Applications WITH GA (structural only)

### 3.1 Feature-interaction explanation for ML models (validated math, unproven product) ⭐
**Idea:** the Möbius interaction spectrum (POC-02-validated) applied to black-box model inputs: compute interaction coefficients over factor subsets and *name* them with the Bagua vocabulary for humans ("the 2-way interaction e12 between latency and cache-miss rate dominates"). This is the same math as Shapley interaction indices, exposed through the blade/subset algebra with a mnemonic naming layer.
**Why honest:** the algebra is exact (V1); the naming is labeling-only; no semantic claim.
**Pre-registration needed:** "do named interaction spectra improve analysts' identification of dominant interactions vs plain tables?" (user study).

### 3.2 Design-space navigation grammar (validated math)
**Idea:** the cube's 8 positions + hexagram stacking as an *exhaustive navigation grammar* for combinatorial design spaces in LLM agents (explore all 8 structural variants of a configuration; stack designs for combined spaces). Guarantees structural diversity by construction.
**Why honest:** the moves are the cube's actual symmetry; the LLM only interprets positions.

### 3.3 The Yarrow product itself (validated → in production plan)
The flagbearer of the with-GA line: see `../products/yarrow-factorial/PRODUCT_SPEC.md`.

## 6. Guiding principles (from 8 experiments)
1. **Structure is I-Ching's gift to AI; semantics is AI's gift to I-Ching.** The framework supplies exact combinatorial structure (bits, flips, duality, 64 states); the LLM supplies interpretation in prose. Never the reverse.
2. **If a component must discriminate, learn it or use learned embeddings.** Fixed hand-assigned axes lose to baselines every time they were tested.
3. **Every unproven adoption is pre-registered** — hypothesis, metric, baseline, kill criterion — before any build (house rule, failure-ledger enforced).
4. **Cultural naming is a feature when stated plainly** ("trigram = 3-factor interaction"), pseudo-science when implied ("hexagram predicts outcome"). The product narrative never implies the latter.
